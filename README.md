# Titipin 📦

**Titipin — Aplikasi Marketplace Barang Preloved Mahasiswa**

Titipin merupakan aplikasi mobile berbasis Android yang dirancang untuk memfasilitasi kegiatan jual beli dan titip jual barang *preloved* di lingkungan mahasiswa Universitas Sumatera Utara (USU).

Aplikasi ini bertujuan menyediakan platform katalog barang terpusat yang memudahkan mahasiswa dalam menawarkan, mencari, dan menemukan barang bekas layak pakai tanpa harus bergantung sepenuhnya pada grup percakapan atau media sosial.

Titipin dikembangkan sebagai *Minimum Viable Product* (MVP) dengan fokus pada kemudahan penggunaan dan enam fitur utama.

## Fitur Utama

1. **Registrasi dan Login Pengguna** — Memungkinkan pengguna membuat akun, masuk, dan keluar dari aplikasi.
2. **Katalog dan Detail Barang** — Menampilkan daftar barang beserta foto, harga, kondisi, dan deskripsi.
3. **Unggah Barang** — Memungkinkan pengguna menawarkan barang dengan mengunggah foto dan informasi barang.
4. **Kelola Barang Saya** — Memungkinkan pengguna mengubah, menghapus, dan memperbarui status barang miliknya.
5. **Pencarian Barang** — Memudahkan pengguna mencari barang berdasarkan nama atau kata kunci sederhana.
6. **Simpan Barang (Wishlist)** — Memungkinkan pengguna menyimpan barang yang diminati untuk dilihat kembali.

## Teknologi

| Teknologi | Kegunaan |
|---|---|
| Flutter & Dart | Pengembangan aplikasi Android |
| Firebase Authentication | Autentikasi pengguna |
| Cloud Firestore | Penyimpanan dan pengelolaan data |
| Cloud Storage for Firebase | Penyimpanan gambar barang |
| Figma | Perancangan UI/UX |
| GitHub | Pengelolaan kode dan kolaborasi tim |
| Trello | Pengelolaan tugas dan progres proyek |

## Ruang Lingkup Proyek

Pengembangan Titipin difokuskan pada enam fitur utama tanpa sistem pembayaran online, verifikasi KTM, dashboard Superadmin, fitur chat internal, maupun layanan pengiriman.

Proses transaksi dan serah terima barang dilakukan di luar aplikasi berdasarkan kesepakatan antara penjual dan pembeli.
